# Varsha Surwade Portfolio

This is a responsive portfolio inspired by the visual structure of the reference website:
https://satyamshelke2005.github.io/

## Files
- index.html — website content
- style.css — design and responsive layout
- script.js — mobile menu + small interactions

## Before publishing
Open `index.html` and replace:
- YOUR_EMAIL@example.com
- YOUR_USERNAME in GitHub link
- YOUR_USERNAME in LinkedIn link
- project links (`href="#"`) with your actual GitHub/demo URLs
- Add your real resume PDF and update the Resume link.

## Run locally
Double-click `index.html`, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR_USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and your resume/assets.
3. Go to Settings → Pages.
4. Select Deploy from branch → main → /(root).
5. Save. Your portfolio will appear at:
   https://YOUR_USERNAME.github.io/
